# リサンプルなう (ResampleNow)

**Spotify・YouTube・音楽プレーヤーなど、Windows で再生中のアプリの音を、高品質にアップサンプリング (疑似ハイレゾ化) して DAC へ出力する、無料のアプリです。**
PCM 最大 1536kHz、DSD64〜DSD1024 (DSD 変換) に対応。WASAPI 排他モード・ASIO・ネイティブ DSD で、DAC に直接送ります。

配信サービスや動画サイトの音は、多くが 44.1kHz / 48kHz です。リサンプルなうは、その音をアプリごとに取り出し、オーディオ用の高精度な変換エンジンでハイレゾのレートや DSD に変換します。
DAC に内蔵された簡易なフィルタの代わりに、PC 側の長く高精度なフィルタで変換するので、どのアプリの音でも、同じ高品質なアップサンプリングで楽しめます。

> 「疑似ハイレゾ」について: アップサンプリングは、元の録音にない情報を作り出すものではありません。変換の精度を上げて、DAC にとって扱いやすい形で届けるための処理です。

## 初めて起動するときの警告について

このアプリは、コード署名をしていません。そのため、初回の起動時に、次のような警告が出ることがあります。

> WindowsによってPCが保護されました

その場合は、**「詳細情報」→「実行」** を押してください。

また、ウイルス対策ソフトが、誤って反応する場合があります。ソースは作者が管理しており、不審な動作はしません。気になる場合は、ご利用をお控えください。

## 主な機能

### 音の取り込みと出力
- 再生中のアプリ (Spotify、ブラウザ、音楽プレーヤーなど) の音を、**そのアプリだけ**取り込めます
- エンジンを起動すると、音を出しているアプリを自動で選びます
- 出力方式は、**WASAPI 共有 / WASAPI 排他 / ASIO** から選べます
- 機器どうしの時計のずれを自動で吸収し、長時間の再生でも途切れません
- 音の処理を Windows に優先してもらう設定 (MMCSS) で、パソコン作業中でも音が途切れにくくなっています

### アップサンプリング (変換エンジン)
- **4 つの変換エンジン**から選べます
  - **r8brain**：高品質で軽い。迷ったらこれ
  - **SoX Resampler (libsoxr)**：定番の高品質エンジン。帯域と精度を細かく選べます
  - **SSRC**：非常に高精度
  - **フィルタ無し / NOS**：補間をしない、NOS DAC のような音
- 位相は **直線位相 / 最小位相 / 中間位相 / アポダイジング** から選べます
- フィルタの性格 (**シャープ / スロー / スーパースロー**)、タップ数・帯域・減衰量を細かく調整できます。選択肢には、音が出るまでの遅れの目安も表示されます
- **フィルタ特性をグラフで表示** (インパルス応答・周波数特性)。設定を変えると、すぐに描き直します
- 再生したまま、変換エンジンや設定を切り替えられます

### 出力形式
- **PCM 44.1kHz〜1536kHz** (16bit / 24bit / 32bit float)
- **DSD64〜DSD1024 (2.8〜45.1MHz)**。PCM から DSD へリアルタイムに変換します
  - ASIO でネイティブ DSD に対応した機器なら**ネイティブ DSD**、それ以外は **DoP** で送ります
  - 1bit にする計算 (ΔΣ 変調) は、標準 (5次) と高精度 (7次) から選べます

### 音質の仕上げ
- **高域補完** (オフ / 弱 / 中 / 強)：圧縮音源で削られた高音を自動で見つけて補います。再生中でも切り替えられます
- **仕上げ**：16bit / 24bit で出すときのディザ (TPDF / ノイズシェーピング)
- **ヘッドルーム**：アップサンプリングで起きる音割れ (インターサンプルピーク) を防ぎます

### そのほか
- リアルタイムのスペクトラムアナライザー。クリックすると、出力の上限まで見られる詳細表示に切り替わります (DSD のときも表示できます)
- 音声退避先の周波数を表示。音源の周波数と合っているかを、ひと目で確かめられます
- お楽しみのサウンドエフェクト (真空管風、8D立体音響、重低音強化、各種リバーブなど)。作者オリジナルのエフェクトも入っています
- **再生中の曲を、X (旧Twitter) へ投稿できます**。書式は自由に編集でき、曲名・アーティスト名のほか、変換エンジンや出力形式も入れられます
  - **Spotify**：Spotify連携 (Spotify Premium 限定) をすると、投稿に曲の URL・高画質のジャケット・複数のアーティスト名を入れられます
  - **YouTube**：再生しているブラウザのタブが表示されている (アクティブな) ときに、投稿に動画の URL と高画質のサムネイルを入れられます
- すべての項目に、カーソルを合わせると説明が出ます
- タスクトレイに常駐できます (クリックでメニュー、ダブルクリックで設定画面)。Windows 起動時の自動起動にも対応しています

## 基本の使い方

1. 「オーディオ設定」タブの「対象アプリ」で、音を取り込むアプリを選びます。
2. 「再生デバイス」と「出力方式」で、再生に使うデバイスと出力方式を選びます。
3. 排他モードや ASIO を使うときは、元の音を流しておく「音声退避先」(VB-CABLE など) を選びます (下の「出力方式の違い」も見てください)。
4. 「高音質化処理」で、変換後の形式 (レート・ビット深度、または DSD) と、変換エンジン、その細かい設定を選びます。
5. 画面下の「エンジン起動」を押すと、変換と再生が始まります。

迷ったときは、変換エンジンに **r8brain** を選び、変換後の形式を DAC が対応している範囲 (例: 96kHz や 192kHz) にするのがおすすめです。

## 出力方式の違い (共有モード・排他モード・ASIO)

「出力方式」は、リサンプルなうが変換した音を、DAC などの再生デバイスへ送る方法です。

| 出力方式 | どんな方式か | ほかのアプリの音 | 音質 |
|---|---|---|---|
| **WASAPI 共有モード** | Windows が、ほかのアプリの音と混ぜてから再生デバイスへ送ります | 一緒に鳴ります | Windows の設定の形式に変換されることがあります |
| **WASAPI 排他モード** | リサンプルなうが再生デバイスを独り占めして、変換した音をそのまま送ります | 再生デバイスからは鳴りません | おすすめ |
| **ASIO** | 機器の ASIO ドライバへ直接送ります (ASIO に対応した機器のみ) | 再生デバイスからは鳴りません | おすすめ。ネイティブ DSD はこちら |

**排他モードや ASIO で起動すると、ほかのアプリの音 (Windows の通知音や、対象アプリ以外の音) は、再生デバイスから聞こえなくなります。これは故障ではありません。**
リサンプルなうが再生デバイスを独り占めしている間、ほかの音は「音声退避先」(VB-CABLE など、聞こえない機器) へ流れるためです。エンジンを停止すると、元どおり聞こえるようになります。

- 音質を優先したいとき：**WASAPI 排他モード** か **ASIO**
- 通知音やほかのアプリの音も、同じ機器で聞きたいとき：**WASAPI 共有モード**

## より良い音で聴くために

リサンプルなうに届く前の音が加工されていると、その分は元に戻せません。次の設定がおすすめです。

- **ロスレスの音源を聴くときは、音声退避先の周波数を音源の周波数に合わせる** (CD 品質の音源やロスレス配信の多くは 44.1kHz)
  - Windows は、アプリの音をいったん退避先の周波数に変換してから渡します。周波数が合っていて音量が最大なら、Windows を通っても音は 1bit も変わりません
  - 変えるときは「サウンド設定」から、退避先のデバイスをダブルクリック →「詳細」タブ →「既定の形式」です
  - 圧縮された音源 (動画サイトなど) は、周波数が違っても差はほとんど分かりません
- Windows のオーディオの機能拡張・立体音響 (空間オーディオ) はオフにする
- 再生するアプリ側では、音量の自動調整 (ノーマライズ・リプレイゲイン)・クロスフェード・イコライザーをオフにし、アプリの音量は最大にする
- 再生するアプリ側の排他モードや ASIO 出力はオフにし、通常の出力にする (オンだと、リサンプルなうに音が届きません)

音楽プレーヤー (foobar2000 など) で手持ちの音源を聴くときも、プレーヤーの出力を通常の出力 (共有モード・DirectSound など) にすれば、同じように使えます。

## DSD 出力について

- **ASIO で、機器がネイティブ DSD (ASIO 2.1 の DSD モード) に対応していれば、ネイティブ DSD で送ります**。それ以外は **DoP (DSD over PCM)** で送ります。どちらで送っても、DAC に届く 1bit の並びは同じです
- DoP で送るときは、**DoP に対応した DAC** が必要です。WASAPI 共有モードでは使えません
- **DSD1024 は上級者向け**です。ASIO ネイティブ DSD で DSD1024 に対応した機器だけで使え、とても重い処理です

## 注意事項

- 排他モードや ASIO では、Windows の「既定の再生デバイス」を、一時的に退避先へ切り替えます。エンジンを停止するか、アプリを終了すると、元に戻ります。異常終了したときは、次の起動時に元へ戻します。
- ASIO では、ドライバ側で、サンプリングレートが固定されている場合があります。エラーが出たときは、ドライバのコントロールパネルで、レートを設定してください。
- 352.8kHz 以上や DSD256 以上は、DAC と PC の性能によっては使えない・重いことがあります。PCM 1411.2kHz / 1536kHz は上級者向けです。デバイスが対応していない形式を選んだときは、起動時にお知らせします。
- 精度の高い設定 (タップ数・帯域・計算の長さが大きいもの) ほど、音が出るまでの遅れが大きくなります。動画を見るときは、遅れの小さい設定がおすすめです。
- 高域補完は、元の録音にない音を推測で足す加工です。原音に忠実に聞きたいときはオフにしてください。
- 大きな音が出ることがあります。初めて使うときは、音量を下げてから起動してください。

## 設定ファイルの場所

設定は、次の場所に保存されます。アンインストールのときに、削除するかを選べます。

- `%LocalAppData%\ResampleNow`
- `%AppData%\ResampleNow`

不具合が起きたときは、`%LocalAppData%\ResampleNow\error.log` に、エラーの記録が残ることがあります。
