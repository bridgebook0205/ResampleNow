リサンプルなう (ResampleNow)
Windows 用のオーディオ再生アプリです。再生中の音声を高音質にアップサンプリングし、スペクトラムアナライザーやお楽しみエフェクトも楽しめます。無料で使えます。
主な機能
• 音声を最大 192kHz / 32bit までアップサンプリング
• 位相の選択（直線位相 / 最小位相 / 中間位相）
• 他のアプリの音声を個別に取り込んで処理
• スペクトラムアナライザー
• お楽しみエフェクト（重低音強化など）
• 再生中の曲を X (旧Twitter) に投稿
• Spotify 連携
• タスクトレイに格納して常駐、Windows 起動時の自動起動に対応
動作環境
• Windows 11 64bit
• .NET のインストールは不要です（アプリに同梱されています）
※ アプリ別の音声取り込み機能は Windows 11 を前提にしています。Windows 10 では正しく動作しない場合があります。
ダウンロード
右側の Releases から、最新版をダウンロードしてください。
• ResampleNow-Setup-バージョン.exe : インストーラー版（おすすめ）
• ResampleNow-バージョン-win-x64.zip : インストール不要の ZIP 版。好きな場所に展開して、中の ResampleNow.exe を起動してください
インストール方法
1.  Releases から Setup.exe をダウンロードします
2.  ダウンロードしたファイルをダブルクリックして、画面の案内に沿って進めます
3.  インストール後、スタートメニューまたはデスクトップのアイコンから起動します
管理者権限は不要です。
初回起動時に「Windows によって PC が保護されました」と表示されたら
このアプリは個人が無料で公開しているもので、有料のコード署名を行っていません。そのため、初めて起動するときに Windows の SmartScreen による警告が表示されることがあります。
1.  警告画面の 「詳細情報」 をクリックします
2.  表示された 「実行」 ボタンをクリックします
一度許可すれば、次回からは表示されません。ご不安な場合は、実行しないでください。
アンインストール
Windows の「設定」→「アプリ」→「インストールされているアプリ」から「リサンプルなう」を選んでアンインストールしてください。ZIP 版は、展開したフォルダを削除するだけです。
