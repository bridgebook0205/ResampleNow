# リサンプルなう (ResampleNow)

再生中のアプリの音を取り込み、高品質にアップサンプリング(リサンプル)して、DACなどへ出力する、Windows用の無料アプリです。
Spotify や YouTube などの音を、そのまま高音質な出力に変換して楽しめます。

## ダウンロード

右側の **[Releases](../../releases/latest)** から、最新版をダウンロードしてください。

| ファイル | 説明 |
|---|---|
| `ResampleNow-Setup-x.x.x.exe` | インストーラー版。通常はこちらがおすすめです |
| `ResampleNow-x.x.x-win-x64.zip` | zip版。展開して、中の `ResampleNow.exe` を実行します |

.NETなどの追加のインストールは、不要です。

## 動作環境

- **Windows 11 (64bit)**
- Windows 10 では、動作を保証していません

## 初めて起動するときの警告について

このアプリは、コード署名をしていません。そのため、初回の起動時に、次のような警告が出ることがあります。

> WindowsによってPCが保護されました

その場合は、**「詳細情報」→「実行」** を押してください。

また、ウイルス対策ソフトが、誤って反応する場合があります。ソースは作者が管理しており、不審な動作はしません。気になる場合は、ご利用をお控えください。

## 主な機能

- 再生中のアプリ(Spotify、ブラウザなど)の音を、そのアプリだけ取り込めます
- 出力方式は、WASAPI 共有 / 排他 / ASIO から選べます
- 補間フィルタは、直線位相 / 最小位相 / 中間位相、タップ数を選べます
- 設定に応じた「処理の重さ」の目安を表示します
- リアルタイムのスペクトラムアナライザー
- お楽しみのサウンドエフェクト
- 再生中の曲を、X (旧Twitter) へ投稿できます。書式は自由に編集できます
- Spotify連携 (Spotify Premium 限定) で、曲のURLや、高画質のジャケットを取得できます
- タスクトレイに常駐できます。Windows起動時の自動起動にも対応しています

## 基本の使い方

1. 「オーディオ設定」タブの「入力ソース」で、音を取り込む対象のアプリを選びます。
2. 「出力デバイス」で、再生に使うデバイスと、出力方式を選びます。
3. 排他モードやASIOを使うときは、元の音を捨てるための「音声退避先」(VB-CABLE など) を選びます。
4. 「高音質化処理」で、出力のレート、位相、タップ数を決めます。
5. 画面下の「エンジン起動」を押すと、変換と再生が始まります。

## 注意事項

- 排他モードやASIOでは、Windowsの「既定の再生デバイス」を、一時的に退避先へ切り替えます。アプリを終了すると、元に戻ります。異常終了したときは、次の起動時に元へ戻します。
- ASIOでは、ドライバ側で、サンプリングレートが固定されている場合があります。エラーが出たときは、ドライバのコントロールパネルで、レートを設定してください。
- タップ数を大きくすると、CPUに負荷がかかります。音が途切れるときは、タップ数か、出力レートを下げてください。
- 大きな音が出ることがあります。初めて使うときは、音量を下げてから起動してください。

## 設定ファイルの場所

設定は、次の場所に保存されます。アンインストールのときに、削除するかを選べます。

- `%LocalAppData%\ResampleNow`
- `%AppData%\ResampleNow`

不具合が起きたときは、`%LocalAppData%\ResampleNow\error.log` に、エラーの記録が残ることがあります。

## アンインストール

「設定」→「アプリ」から、「リサンプルなう」を削除してください。zip版は、フォルダを削除します。
