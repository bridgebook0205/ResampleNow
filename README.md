# リサンプルなう (ResampleNow)

再生中のアプリの音を取り込み、高品質にアップサンプリング(リサンプル)して、DACなどへ出力する、Windows用の無料アプリです。
Spotify や YouTube などの音を、そのまま高音質な出力に変換して楽しめます。

## ダウンロード

右側の **[Releases](../../releases/latest)** から、最新版をダウンロードしてください。

| ファイル | 説明 |
|---|---|
| `ResampleNow-Setup-x.x.x.exe` | インストーラー版。通常はこちらがおすすめです |
| `ResampleNow-x.x.x-win-x64.zip` | zip版。展開して、中の `ResampleNow.exe` を実行します |

.NETなどの追加のインストールは、不要です。

## 動作環境

- **Windows 11 (64bit)**
- Windows 10 では、動作を保証していません

## 初めて起動するときの警告について

このアプリは、コード署名をしていません。そのため、初回の起動時に、次のような警告が出ることがあります。

> WindowsによってPCが保護されました

その場合は、**「詳細情報」→「実行」** を押してください。

また、ウイルス対策ソフトが、誤って反応する場合があります。ソースは作者が管理しており、不審な動作はしません。気になる場合は、ご利用をお控えください。

## 主な機能

- 再生中のアプリ(Spotify、ブラウザなど)の音を、そのアプリだけ取り込めます
- 出力方式は、WASAPI 共有 / 排他 / ASIO から選べます
- **3 つの変換エンジン**から選べます
  - **r8brain**：高品質で軽い。迷ったらこれ
  - **SoX Resampler (libsoxr)**：定番の高品質エンジン。帯域と精度を細かく選べます
  - **SSRC**：非常に高精度
  - タップ数・帯域・位相 (直線 / 最小 / 中間)・減衰量を細かく調整できます。選択肢には、音が出るまでの遅れの目安も表示されます
  - 再生したまま、変換エンジンや設定を切り替えられます (音は途切れません)
- 出力形式は、**PCM 44.1kHz〜768kHz** と、**DSD64〜DSD512 (2.8〜22.4MHz、DoP 方式)** に対応しています
- **高域補完** (オフ / 弱 / 中 / 強)：元の録音の上限より上の高音を、元の音をもとに補います。再生中でも切り替えられます
- 機器どうしの時計のずれを自動で吸収し、長時間の再生でも途切れません
- 設定に応じた「処理の重さ」の目安を表示します
- リアルタイムのスペクトラムアナライザー。クリックすると、出力の上限まで見られる詳細表示に切り替わります
- お楽しみのサウンドエフェクト
- 再生中の曲を、X (旧Twitter) へ投稿できます。書式は自由に編集でき、変換エンジンや出力形式も入れられます
- Spotify連携 (Spotify Premium 限定) で、曲のURLや、高画質のジャケット、複数のアーティスト名を取得できます
- すべての項目に、カーソルを合わせると説明が出ます
- タスクトレイに常駐できます。Windows起動時の自動起動にも対応しています

## 基本の使い方

1. 「オーディオ設定」タブの「入力ソース」で、音を取り込む対象のアプリを選びます。
2. 「出力デバイス」で、再生に使うデバイスと、出力方式を選びます。
3. 排他モードやASIOを使うときは、元の音を捨てるための「音声退避先」(VB-CABLE など) を選びます。
4. 「高音質化処理」で、変換後の形式 (レート・ビット深度) と、変換エンジン、その細かい設定を選びます。必要なら「高域補完」も選びます。
5. 画面下の「エンジン起動」を押すと、変換と再生が始まります。

迷ったときは、変換エンジンに **r8brain** を選び、変換後の形式を DAC が対応している範囲 (例: 96kHz や 192kHz) にするのがおすすめです。

## DSD 出力について

- DSD は **DoP (DSD over PCM)** 方式で出力します。**DoP に対応した DAC** が必要です
- ASIO での出力がおすすめです。WASAPI 共有モードでは使えません
- DoP に対応していない DAC (ASIO ネイティブ DSD のみに対応した機種など) では、DSD は再生できません。その場合は PCM の高いレートをお使いください

## 注意事項

- 排他モードやASIOでは、Windowsの「既定の再生デバイス」を、一時的に退避先へ切り替えます。エンジンを停止するか、アプリを終了すると、元に戻ります。異常終了したときは、次の起動時に元へ戻します。
- ASIOでは、ドライバ側で、サンプリングレートが固定されている場合があります。エラーが出たときは、ドライバのコントロールパネルで、レートを設定してください。
- 352.8kHz 以上や DSD256 以上は、DAC と PC の性能によっては使えない・重いことがあります。デバイスが対応していない形式を選んだときは、起動時にお知らせします。
- 精度の高い設定 (タップ数・帯域・計算の長さが大きいもの) ほど、CPUに負荷がかかり、音が出るまでの遅れも大きくなります。動画を見るときは、遅れの小さい設定がおすすめです。
- 高域補完は、元の録音にない音を推測で足す加工です。原音に忠実に聞きたいときはオフにしてください。
- 大きな音が出ることがあります。初めて使うときは、音量を下げてから起動してください。
- 本アプリの使用による、機器やデータの損害について、作者は責任を負いません。自己責任でご利用ください。

## 設定ファイルの場所

設定は、次の場所に保存されます。アンインストールのときに、削除するかを選べます。

- `%LocalAppData%\ResampleNow`
- `%AppData%\ResampleNow`

不具合が起きたときは、`%LocalAppData%\ResampleNow\error.log` に、エラーの記録が残ることがあります。

## アンインストール

「設定」→「アプリ」から、「リサンプルなう」を削除してください。zip版は、フォルダを削除します。
